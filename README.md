# Big Cat Genomes

A one-page science site about the DNA and origins of the big cats: lions, tigers, jaguars, leopards and snow leopards, plus clouded leopards, cheetahs and pumas.

**Chapters:** origins timeline · interactive family tree · genome projects (2013–2026) · ancient hybridization and ligers · coat-color genes · ancient DNA · conservation genetics · open questions · key papers with DOIs.

Researched in November 2026 from the primary literature. Some 2025–2026 figures came from abstracts or press releases; check the original paper before citing a number.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` or view it on GitHub Pages.
